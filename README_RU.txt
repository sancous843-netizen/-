ПАЗ Вектор NEXT — Холмск (Android-проект)

Это проект приложения Android Studio, который открывает игровую HTML-версию внутри полноэкранного Android-приложения. Сам APK в этом архиве не собран.

Как получить APK:
1. Установите Android Studio на компьютер.
2. Распакуйте архив.
3. В Android Studio выберите Open и укажите папку PAZ_Vector_Kholmsk_Android.
4. Дождитесь синхронизации Gradle и установки Android SDK Platform 35 (если IDE попросит).
5. В меню Build выберите Build Bundle(s) / APK(s) > Build APK(s).
6. APK будет в app/build/outputs/apk/debug/app-debug.apk. Перенесите его на Android и установите. При запросе разрешите установку из выбранного источника.

Управление: сенсорные кнопки на экране. Это прототип: 2D-сцена, выбор условных маршрутов, двери, счётчик пассажиров и текстовый информатор. Это не полноценная 3D-игра и пока нет настоящего озвучивания объявлений.
